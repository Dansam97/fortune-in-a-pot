A tiny Python program that writes one kind, funny fortune for a houseplant — a single line of at most 120 characters, told in the cadence of a prediction — to `entry.txt` in the output directory, for make.fun's "Fortune in a Pot" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
